# 音乐结构与和声分析工作台

一个音乐课堂分析工具，包含两个模块：

- 交互式和声分析工作台：调性地图、和弦标注、四部和声检查、功能路径、错误诊断和配和声比较。
- 曲式结构工具：上传 MusicXML 或乐谱图片，生成可复核的曲式分段草稿；也保留结构卡片时间轴、课堂模式、提交反馈与统计。

## 乐谱曲式分析流程

- 图片：Audiveris 5.11 将谱面识别为 MusicXML。
- MusicXML：music21 提取逐小节音高类别、音区、密度、调性与终止提示。
- `librosa.segment`：建立自相似关系并提出段落边界。
- MSAF：在逐小节符号特征上运行谱聚类，作为第二套边界意见；不要求学生上传音频。
- Taking Form：采用呈示部、展开部、再现部、引子、尾声等分析术语与层级规则；已有 Taking Form 标注时也会读取。

自动结果始终显示为“候选/草稿”。教师或学生手工结构是主答案，不会被机器结果自动覆盖。

## 使用方法

首次运行双击 `start-score-form-server.command`，等待终端显示 `http://127.0.0.1:8790` 后，再打开 `dist/index.html`。乐谱只发送到本机服务，不会上传到互联网。

已验证格式：`.xml`、`.musicxml`、`.mxl`、JPG、PNG、WEBP、TIFF。图片应清晰、方向正确，并尽量包含完整谱号、调号与小节线。

## 公开版本

静态 GitHub Pages 只能展示前端；图片识谱与 MusicXML 深度分析需要运行 Python/Audiveris 后端，因此公开版本应部署到支持后端进程的平台。
